# 生成与引用

## 提示词约束

提示词明确要求「严格依据下面的资料回答，不要编造资料之外的内容」，
并要求资料不足时直接说明没有相关信息。

## 引用编号

拼上下文时每段资料都带一个编号，格式是 `[1] 来源：文件（标题路径）`。
模型被要求用 `[1]` `[2]` 这样的编号标注依据，编号必须和资料列表对应。
接口返回的 sources 里带着 source、heading、ordinal、score 和正文前 80 字预览，
前端可以据此把引用渲染成可点击的来源。

## 无命中兜底

### 为什么命中为空时不调用模型

检索结果为空时直接返回「知识库中没有找到相关内容。」，一次模型调用都不发。
两个原因：一是此时上下文里没有任何依据，模型只能编，等于花钱买幻觉；
二是这种情况往往是用户问了自己知识库没覆盖的问题，直接告诉他比编一个答案更有用。

## 回答的可信度

答案里保留引用编号，用户能顺着编号回到原文核对。
把「模型说了什么」和「依据在哪」分开，是让 RAG 敢用的前提。
