# 错误与边界

## 切分参数

chunk_size 小于等于 0，或者 overlap 不满足 0 <= overlap < chunk_size，都抛 ValueError。
参数错的代价不是报错，而是检索质量悄悄变差，所以宁可在入口就崩。

## 向量维度不一致

查询向量和库内向量维度不同时抛 ValueError，并带上两个维度值。
常见原因是换了 embedding 模型却没重建索引。

## top_k 非法

top_k 小于等于 0 时抛 ValueError，store 和 BM25 都做这个校验。

## 检索器数量

HybridRetriever 要求至少传入一个检索器，空列表抛 ValueError。
没有检索器的混合检索没有意义，与其返回空结果不如直接报错。

## RRF 的 k

RRF 的 k 必须大于 0，否则抛 ValueError。
k 出现在分母上，取 0 会让名次第一的项直接除零。

## 空知识库

库为空时检索返回空列表，不抛异常。
「还没有导入任何文档」是正常状态，不是错误，上层会走无命中兜底。

## 无命中不等于报错

检索结果为空时 RagService 返回兜底话术，used_llm 为 false。
把「没找到」当成一种正常结果返回，接口调用方不需要写 try/except。

## HTTP 层

FastAPI 的请求体校验失败返回 422。
业务异常和参数异常分开：422 是调用方的问题，500 才是服务的问题。

## 为什么不返回 None

内部接口选择抛异常而不是返回 None 或空值。
None 会被一路传下去，等到很远的地方才炸，栈里已经看不出根因。
