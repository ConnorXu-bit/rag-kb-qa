# 文档切分

## 切分粒度

默认 chunk_size 是 500 个字符，overlap 是 80。
一个片段的正文长度不会超过 chunk_size 加 overlap，因为重叠的尾巴会和下一段一起入库。

## 标题路径

每个片段都会带上它所属的标题路径，用 ` > ` 连接，例如检索设计下的 RRF 融合一节会记成两级路径。
这样做是因为切片之后单块会失去上下文：一句「所以只融合名次」离开标题就看不懂在说什么。
检索结果里返回标题路径，用户也能一眼看出答案出自哪一节。

## 重叠窗口

相邻片段保留一段重叠，避免关键句子正好被切在边界上。
重叠取自上一块的尾部 overlap 个字符，作为下一块的开头。

## 参数校验

overlap 必须满足 0 <= overlap < chunk_size，否则直接抛 ValueError。
这个校验是有意为之：overlap 大于等于 chunk_size 不会让程序崩，
只会让重叠的尾巴比整块还长，块越滚越大，最后整个文档挤成一两块。
检索质量崩掉却没有一行报错，这种静默错误比崩溃难查得多。
