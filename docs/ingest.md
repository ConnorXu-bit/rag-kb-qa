# 入库流程

## 三个步骤

入库就是切分、向量化、写库三步。
先切分再向量化，是因为要向量的是一段段片段，不是整篇文档。

## 幂等保证

同一 source 先删旧片段再写新片段，所以重复导入不会让库膨胀。
代价是每次导入都要删一次，换来的是调用方不用记「我导过没有」。

## 返回值

返回这次真正写进去的片段数。
调用方可以用它确认切分有没有产出，比如 0 就说明文档是空的。

## 空文档

切不出任何片段时直接返回 0，不写库也不报错。
空文档不算错误，但静默返回 0 让调用方有机会发现异常。

## 目录导入

ingest_dir 递归读取目录下所有 .md 文件，source 用相对路径。
用相对路径而不是绝对路径，是为了让检索结果里的来源可读、可移植。

## 目录不存在

目录不存在时抛 NotADirectoryError，而不是返回 0。
路径写错和文档是空的，是两种完全不同的情况，不该有一样的表现。

## 顺序可复现

目录导入按路径排序后再处理。
排序让同一份语料每次跑出来的片段顺序一致，评估结果才可复现。

## 批量向量化

一篇文档的所有片段一次性交给 embedder，而不是逐条调用。
真实 embedding 接口按批计费、按批限速，批量提交比逐条快得多。
