# 排查记录

## 文件名被系统改写

新建文件时路径里的斜杠被当成了文件名的一部分，app/main.py 变成了 app:main.py。
表现是启动报 Could not import module "app.main"，看目录才发现文件根本不叫这个名字。

## 粘贴代码多出缩进

从聊天窗口复制代码，每行前面多了两个空格，运行直接 IndentationError。
检查方法是看第一行是否顶格，预防方法是用纯文本粘贴。

## 结束标记带了空格

用终端写文件时卡在 heredoc 提示符上，原因是结束标记两边带了空格，shell 不认。
解决办法是重新粘贴，或者按 Ctrl+C 退出，别在里面继续敲。

## 参数校验缺位的代价

overlap 大于等于 chunk_size 不会崩，只会让重叠尾巴越滚越长，最后整个文档挤成一两块。
检索质量崩掉却没有一行报错，这种静默错误比崩溃难查得多，所以才补上参数校验。

## 测试替身保存了引用

测试里的假客户端保存的是参数对象的引用而不是快照，调用方之后修改对象，断言看到的是改过之后的状态。
结果是测试假绿。修法是在替身里做深拷贝，教训是测试替身必须做快照。

## 文档和实现不一致

文档里写的是 ReAct 循环，实现其实是单轮调用。
处理方式是改实现让它名副其实，而不是把文档改弱去迁就代码。

## 报错要从下往上读

一次跑出十几个红色，其实只有一个根因，其余都是连锁反应。
先看最后的汇总行，再区分 FAILED 和 ERROR：前者是断言失败，后者是夹具阶段就挂了。

## 先让它能跑

完整文件搬了四次全部失败，改成十五行的最小可运行版本一次通过。
先把链路打通，再往上加功能，比一次性写完整版更容易定位问题。

## 终端不是编辑器

长内容往终端里粘，引号和结束标记极容易不闭合，卡在等待输入的提示符上。
写文件该用编辑器或脚本，终端只用来执行命令。
